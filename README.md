# FreeRTOS on AFTx08

This project is based on [FreeRTOS 202212.00](https://github.com/FreeRTOS/FreeRTOS/tree/202212.00),created for porting FreeRTOS and benchmark applications to AFTx08, which is a microcontroller of Purdue-SoCET orgs.


## Repository Structure

```text
.
|-- FreeRTOS/
|   |-- Source/                         # FreeRTOS kernel source
|   `-- Demo/
|       `-- AFTx08/                     # Main project directory
|           |-- FreeRTOSConfig.h        # Kernel configuration
|           |-- main.c                  # Platform entry point
|           |-- main_blinky.c           # Active benchmark/demo entry
|           |-- main_fpga.c             # FPGA demo entry
|           |-- riscv-virt.c/.h         # AFTx08 platform memory address
|           |-- uart.c/.h               # UART output support
|           |-- vector.S                # interrupt vector table
|           |-- build/gcc/              # RISC-V GCC build files
```

`FreeRTOS/Demo/AFTx08/build/gcc/output/` should be ignored from version control because they are rebuilt locally.

## Requirements


```sh
riscv64-unknown-elf-gcc --version
```

The demo has been developed with the  `riscv64-unknown-elf` GCC toolchain family.

## Setup

```sh
cd FreeRTOS
git submodule update --init --recursive
```

If the toolchain is not already in `PATH`, add it before building:

```sh
export PATH="/path/to/riscv64-unknown-elf/bin:${PATH}"
```

## Build

Build the AFTx08 demo:

```sh
make -C FreeRTOS/Demo/AFTx08/build/gcc
```

 disassembly:

```sh
make -C FreeRTOS/Demo/AFTx08/build/gcc clean
```

Successful builds generate:

```text
FreeRTOS/Demo/AFTx08/build/gcc/output/RTOSDemo.elf
FreeRTOS/Demo/AFTx08/build/gcc/output/RTOSDemo.bin
FreeRTOS/Demo/AFTx08/build/gcc/output/RTOSDemo.map
FreeRTOS/Demo/AFTx08/build/gcc/output/RTOSDemo.disassemble
```

## Running on Verilator

1. Build `RTOSDemo.bin`.
2. Copy the binary into the AFTx08 simulation repository as the memory initialization image.
3. Run the AFTx08 Verilator executable from the AFTx08 repository.

Example:

```sh
cp FreeRTOS/Demo/AFTx08/build/gcc/output/RTOSDemo.bin /path/to/AFT-dev/meminit.bin
cd /path/to/AFT-dev
./aft_out/sim-verilator/<simulator-binary>
```

Use the simulator path and binary name generated by your AFTx08 build.

## Running on FPGA (not tested)

1. Build `RTOSDemo.bin`.
2. Convert the binary into the FPGA memory initialization format:

```sh
./bin_to_mif RTOSDemo.bin meminit.mif
```

3. Replace the FPGA memory initialization file with `meminit.mif`.
4. Rebuild or reload the FPGA image as required by the AFTx08 flow.
5. Program the board.


## Key Configuration Files

- `FreeRTOS/Demo/AFTx08/FreeRTOSConfig.h`: tick rate, heap size, task stack settings, hooks, and scheduler options.
- `FreeRTOS/Demo/AFTx08/riscv-virt.h`: AFTx08 platform constants, including CLINT base addresses and demo-selection macros.
- `FreeRTOS/Demo/AFTx08/build/gcc/fake_rom.ld`: linker script.
- `FreeRTOS/Demo/AFTx08/build/gcc/Makefile`: source list, architecture flags, output names, and clean rule.
